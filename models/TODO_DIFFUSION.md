## 方法优势

当前已有整图视觉 tokens、按笔顺生成的笔画 token，以及笔画 mask / 类别监督。
在此基础上，用一个小型 action expert 根据视觉和笔画条件生成整笔连续轨迹，
用 conditional flow matching（CFM）训练该网络，可以复用已有视觉与笔画表示，重点替换成本最高的逐点生成部分。

1. **减少训练中的串行展开。** 当前 free rollout 要先生成上一点，再生成下一点，
   并对整段生成历史做完整 BPTT。标准 CFM 训练随机抽取一个噪声时间，
   对整笔所有点做一次速度场预测和反向传播，不需要先完成多步采样。
   这是预期的计算优势，具体吞吐和显存仍须在相同轨迹表示下实测。
2. **整笔点可以并行交互。** 有序点 tokens 使用双向自注意力，
   起笔、中段、收笔可共同参与形状建模；不同有效笔画也可以批处理。
   推理仍需多次积分更新，但每次更新处理整笔所有点，点数不等于采样更新次数。
3. **自然使用现有条件。** 整图 tokens 提供布局，笔画 token 提供当前笔身份及上下文，
   预测类别和 mask 可提供形态及空间条件；不需要为该任务额外引入大型 VLM。
4. **保留连续几何与宽度建模。** 输出覆盖整笔的 x、y、width，
   轨迹顺序由点位置编码表示，可共同学习曲线及粗细变化。
   连贯性和宽度准确度不是结构自动保证的性质，仍需指标与约束验证。
5. **有机会建模轨迹歧义。** 相同墨迹可能对应不同方向或路径，噪声条件生成允许表达多种解。
   但当前单图通常只有一条标注，1915 样本也较少，不能预先认定多样性或准确率优于直接回归。
6. **可调推理计算量。** 显式设置积分器和采样步数，比较 8 / 16 / 32 步的质量、延迟，
   在验证后选择部署配置；不把“更少采样步”直接等同于更好或更快的模型。

这些优势是本项目的设计动机，尚未由实验确认。固定长度并行回归同样能减少逐点串行开销，
必须作为对照，区分“并行表示带来的收益”和“flow matching 本身的收益”。

## 目标与首版边界

- 输入仍为整张单字图像；推理不输入真实笔画数、mask、类别、起终点或轨迹。
- 复用图像编码器与有序笔画解码器；首版 action expert 的隐藏维度以 dim=128 为起点。
- 每笔固定表示为 P=64 个有序点，P=128 作为对照；生成连续量 `[x,y,width]`。
- 笔画层预测最后一笔，负责整字停止；每笔固定点数，其最后一点代表该笔结束。
- 原有 `last_head` 目前仅是辅助头；让它参与实际停止属于本方案需要实现和验证的行为变化。
- 首版不要求保留原始点数或机器人运动时间。需要恢复采样密度时另做长度预测 / 重采样；
  需要控制书写速度时另建时间或速度表示，不能将 flow 时间当作物理书写时间。
- 独立训练模式、配置、checkpoint 与输出目录；本 TODO 不改动正在运行的 free rollout 作业。
- 首版沿用随机初始化策略，旧逐点 decoder 权重不能直接作为 action expert 权重使用。

## 核心计算与张量约定

Action expert 是预测速度场的网络；flow matching 是训练它的路径构造和监督方法；
采样器是在推理时调用该网络并进行数值积分的组件，三者分别实现。

```text
图像 → 编码器 → 整图视觉 tokens V [B,M,D]
                  ↓
        有序笔画解码器 → z_k、预测 mask/type/last
                  ↓
带噪轨迹 X_t [N,P,3] + 点序号 + 噪声时间 t + 笔画条件
                  ↓
        Action Expert：点间双向 self-attention
                       对整图 tokens 做 cross-attention
                  ↓
              速度场 v [N,P,3]
```

B 是图片数，N 是当前批次实际参与几何训练 / 采样的笔画数，M 是视觉 token 数，D 是隐藏维度。
N 不等于 B。batch=24 张图片可能包含上百笔，必须记录并控制有效笔画批次的显存。

对变换到模型空间的真实轨迹 X 和高斯噪声 Z，首版采用直线路径：

```text
t ~ Uniform(0,1)
Z ~ Normal(0,I)
X_t = (1-t) * Z + t * X
目标速度 u = X - Z
L_FM = mean((v_theta(X_t, t, C) - u)^2)
```

C 为整图与当前笔画的预测条件。t 是噪声到轨迹的积分时间；点序号是笔内书写顺序，
两种编码必须分开。速度场 v 的三个分量对应模型空间的 x、y、width 变化，不是落笔物理速度。

推理从随机 Z 开始，首版使用固定步数 Euler：

```text
X_0 = Z
S = num_sampling_steps
for j in range(S):
    t = j / S
    X = X + v_theta(X, t, C) / S
```

训练通常只采一个 t，不对上述 S 次采样循环做反传。推理中间的几何量不保证逐步提高 IoU。

## P0：确定数据表示与生成语义

- [ ] 实现逐笔重采样：首版按累计 XY 弧长采样 P=64 点，插值对应位置的宽度，保留方向和端点。
  不跨笔插值；覆盖重复点、零长度笔画、单点笔画、极短笔和闭合路径。
- [ ] 检查重采样后 label 重绘 IoU、端点和宽度误差；与 P=128 比较，确认表示本身的精度上限。
  当前 free rollout loss 使用均匀点索引重采样，不能未经说明当作同一表示对照。
- [ ] 定义可逆坐标变换：候选为 x/y 从画布归一化到 [-1,1]，width 使用正值对数变换再标准化。
  尺度统计只用训练集，写入配置和 checkpoint；明确数值 epsilon 及逆变换。
- [ ] 不对速度输出使用 sigmoid / softplus；其各分量须允许正负值。
  中间带噪点允许超出画布；明确最终越界处理并报告原始越界率，不在每步积分后随意裁剪。
- [ ] 确定按笔画序号关联 z_k 与标签路径；类别使用预测概率的软嵌入，mask 使用预测软偏置。
- [ ] 明确训练覆盖全部真实有效笔画，不因预测 last 提前结束而丢掉后续几何 / 视觉监督。
  真实笔画数只用于训练标签组织；推理必须自行预测笔画数，并单独评估该差异。
- [ ] 定义 last 的阈值、最少一笔、最大笔数和到达上限的截断状态。
  不根据真实笔画数停止，也不把达到保护上限伪装成正常结束。
- [ ] 定义导出兼容格式：每笔 P 点拼接成 `points[T,6]`，中间点为 continue，
  每笔末点为 stroke_end，预测最后一笔末点为 drawing_end；offsets 从生成笔数和 P 派生。
  截断输出的真实状态与仅用于显示的补边界分开记录。

## P1：实现 Action Expert 与条件接口

- [ ] 对每笔加入所属图片索引和笔画序号，确保视觉条件、mask 偏置与笔画一一对应。
- [ ] 首版复用 `separate_branches=true` 的梯度隔离原则：视觉 memory、z 和预测 mask/type
  在几何分支入口 detach，action expert 自己的条件投影 / 类别嵌入可训练；后续再消融联合训练。
- [ ] 采样循环外缓存视觉与笔画条件；不可缓存随 X_t 或 t 改变的点特征。
- [ ] 支持 batch=24 张图下的有效笔画并行；必要时按笔画 microbatch，
  保持每图 / 每笔的约定权重和完整梯度，不将 microbatch 误记为图片 batch。

## P3：正确性与评估

- [ ] 验证重采样 / 可逆变换、轨迹形状、宽度正值、方向、端点及边界事件导出。
- [ ] 固定模型、图像和生成 seed，改变监督轨迹 / mask / 类别 / 笔数时，图像条件推理输出不变。
  训练 X_t 本来包含带噪标签，这是 CFM 监督机制，不应错误要求训练输出与标签无关。
- [ ] 测试速度目标方向和积分方向一致；用常量已知速度验证采样器可还原指定终点。
- [ ] 检查不同笔数、尾批和笔画 microbatch 的损失 / 梯度归一化一致，padding 无贡献。
- [ ] 验证 action expert 梯度有限，开启分支隔离时几何损失不更新视觉分支；
  同批不同图片之间的视觉条件与噪声不串样本。
- [ ] 验证相同 seed 的采样可复现（注明设备数值限制），不同 seed 的轨迹差异及质量稳定性。
- [ ] 在固定训练图和独立验证图分别报告：image-only 重绘 IoU、笔画数准确率、截断率、

- [ ] 对错误笔数明确匹配和缺失 / 额外笔画的评估规则，不只统计正确匹配笔画。
  已知笔数 / 已知条件的 oracle 评估单独列出，不代替完整 image-only 结果。
- [ ] 报告训练 images/s、有效 strokes/s、每步时间和峰值显存；
  采样报告包含视觉编码、笔画生成与积分的端到端延迟，并注明 P、S、生成笔数、batch 和精度。

完成标准：不读取真值条件即可生成合法有序轨迹；可保存恢复；小集可拟合；
