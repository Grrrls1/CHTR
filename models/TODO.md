## P1：先实现并验证单笔轨迹阶段

- [x] 新增逐笔 Dataset，以 `(sample_id, stroke_index)` 索引 PNG 与对应轨迹；
  保留原始有效点，校验 mask / trajectory 坐标一致与标签上限，不静默截断。
- [x] 单笔视觉输入使用当前笔画 mask 区域内的原图内容，区域外填充白色，形成256×256 PNG，
  保留笔画在整字画布中的位置与粗细 / 灰度信息；首版不将单笔裁剪后单独居中或拉伸。
  训练使用真实 mask 提取原图内容，串联推理使用预测 mask 提取同一张原图的对应内容，
  不将二值 mask 本身直接当作第二阶段视觉输入。统一 mask 二值化、填充与图像归一化规则。
  原图内容必须映射到轨迹对应的规范化整字画布；若读取 original_image_key，先应用一致的空间变换，
  不将其直接与 image_key 坐标混用。核验已有单笔 PNG 是否符合此构造，不符合则在数据适配层构造。
- [x] 当前单笔图片经独立共享 ResNet、Transformer Encoder 和 FPN 得到多尺度视觉特征。
  所有笔画共用参数；这里的“独立”表示重新编码单笔图像，不是每笔一个网络。
- [x] 点层使用 BOS、历史点 embedding、位置编码和因果注意力，
  按论文以 P5 → P4 → P3 → P2 四尺度串行交互，解码块堆叠4层；
  XY 使用 sigmoid 对应归一化画布坐标，不默认接收第一阶段隐藏 z 或整字视觉 tokens。
- [x] 按论文采用 teacher forcing，并将真实历史扩展为包含宽度：训练预测第 l 个点时，
  输入第1至l−1个点全部真实的 `(x, y, width)`，而非只给真实首点后反馈中间预测点。
  首点 XY 和宽度均直接给真实值，从第二点开始预测 XY、宽度与点有效性。
  历史点 embedding 包含 XY 和宽度；使用因果注意力和正确移位，不能读取当前目标或未来点。
  自由解码使用预测历史；跨阶段推理首点 XY 和宽度直接取笔画层预测的 u_k=(x_k,y_k,w_k)，
  第二阶段不重新预测该首点三元组。明确 BOS、首点输入和后续点监督的移位对齐。
- [x] 首版同时预测 XY、宽度和点有效性，宽度为必需输出，不推迟到后续版本。
  损失为后续有效点坐标 L1 + 0.2 × 点有效性 BCE + λ_width × 后续有效点宽度损失；
  λ_width=1；宽度采用softplus+1e-6、以256归一化，Charbonnier的epsilon为0.01/256，
  减去epsilon偏置；损失先每笔平均再对笔平均。这些属于书法扩展，不是论文原设定。
  在真实末点后追加无效位置，仅算有效性损失，不算坐标或宽度损失。
- [x] 点有效性阈值初始按论文取 0.5；已测试无效候选不保存、有效点保留，
  区分invalid正常停止与点数上限截断，不与“最后一个有效点标为结束”的旧约定混用。
- [x] 首点真实 XY / 宽度作为训练条件，不作为第二阶段需重新预测的目标；后续有效点包含宽度监督。
  给定真实首点 XY / 宽度的自由解码仅作条件诊断，明确使用了标签。
  完整 image-only 推理的首点宽度由笔画层扩展的 u_k 宽度头提供，不读取真实首点宽度。
  论文没有宽度头；记录该扩展，并单独验证宽度损失尺度、梯度贡献及粗细拟合。
- [x] 已做单笔128步、小量8笔32步、固定32字334笔一轮训练，以及条件自由解码 / 保存恢复 / 导出检查。
  smoke使用dim32、视觉encoder1层，点解码仍为四尺度4层；没有继承旧训练配置。
- [ ] 完成固定32字充分拟合、留出自由解码质量验收及GPU容量测试；本机CUDA不可用，CPU短跑不能代替这些结论。
