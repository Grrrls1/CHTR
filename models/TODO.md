  比例与随机种子可配置，首版建议 80% / 10% / 10%；按组划分时记录实际比例与数量。
  检查同源图片、精确重复与近重复，相关样本成组分配；缺少来源信息时明确检查范围和限制。

## P1：先实现并验证单笔轨迹阶段

- [ ] 当前单笔图片经独立共享 ResNet、Transformer Encoder 和 FPN 得到多尺度视觉特征。
  所有笔画共用参数；这里的“独立”表示重新编码单笔图像，不是每笔一个网络。
- [ ] 点层使用 BOS、历史点 embedding、位置编码和因果注意力，
  依次读取由粗到细的视觉特征；不默认接收第一阶段隐藏 z 或整字视觉 tokens。
- [ ] 按论文采用 teacher forcing；训练真实历史，推理预测历史。
  给定正确首点时先验证后续轨迹拟合；跨阶段推理首点取第一阶段预测结果。
- [ ] 论文原型先预测 XY 与点有效性：有效点坐标 L1 + 0.2 × 点有效性 BCE。
  在真实末点后追加无效位置，仅算有效性损失，不算坐标损失。
- [ ] 点有效性阈值初始按论文取 0.5；无效位置的保存 / 丢弃规则需明确并测试，
  不与“最后一个有效点标为结束”的旧约定混用。
- [ ] 宽度数据继续保留。论文没有宽度头；加入宽度属于书法扩展，
  与 XY 原型分别记录，损失尺度、梯度贡献和粗细拟合单独验证。
- [ ] 顺序做单笔、小量多笔、固定32字的小集拟合及 GPU 容量测试；
  不直接继承 batch24 / dim128 / 500轮，先确定可运行且可拟合的配置。
