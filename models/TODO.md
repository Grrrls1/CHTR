## 方法优势与验证目标

首版保留 ResNet-18/FPN、整图视觉 tokens、笔画 Transformer 和笔内点 Transformer，
只验证三个主任务：实际轨迹几何、当前笔结束、整字结束。

1. **停止职责明确。** 笔画层预测当前笔是否为最后一笔，点层预测当前点是否为本笔最后一点。
   不再让点层同时区分换笔和整字结束，不新增数量预测头；笔数和点数从推理停止位置派生。
2. **几何监督覆盖全部原始点。** 训练按真实有效长度展开，停止预测不裁掉监督，
   无需把预测和标签压缩到64点，也无需为未生成的几何张量填入常量零。
3. **便于判断问题来自哪里。** 只保留三个主损失，将几何拟合和停止质量分别评估，
   避免先加入很多辅助项再难以定位收益。
4. **具备明确的消融起点。** 首版直接使用 z_k 和整图视觉 tokens；mask/type 条件、端点等增强
   仅在基线验证后单独比较，不把它们的收益预先视为事实。

这些是设计动机，不是已验证的性能结论。训练仍逐点自回归并保留完整跨步梯度；
训练按标签长度展开、推理按预测停止，两者存在差异，必须用真实停止的 image-only 评估验收。

## 首版结构与接口

```text
灰度整字图像
    ↓ ResNet-18 + FPN
整图视觉 tokens V
    ↓
笔画 Transformer：BOS、历史预测笔画 tokens、笔画序号 → z_k
    ├─ 笔画结束头 → 当前笔是否最后一笔
    └─ 当前笔条件 c_k = projection(z_k)
             ↓
点 Transformer：点 BOS / 自预测上一点 xyz、点序号、c_k
               通过 cross-attention 读取 V
    ├─ 几何头 → x,y,width
    └─ 点结束头 → 当前点是否本笔最后一点
```

首版仅保留三个任务输出头。两个结束头各自输出一个 logit，使用 sigmoid 解释为结束分数，参数不共享。

- [x] 删除新基线中的 mask/type 输出分支、类别软嵌入、mask 视觉注意力偏置及其监督。
  它们在旧网络里确实参与生成条件，本次是明确暂时移除这条条件路径，不是声称它们没有作用。
- [x] 删除 endpoint 辅助头与辅助监督；现有 `last_head` 转为真正控制整字结束的主任务头。
- [x] 点层三分类状态头改为二分类本笔结束；历史输入只使用预测 `[x,y,width]`，不反馈旧六维事件 one-hot。
- [x] 几何输出保留 XY sigmoid 和 width softplus，输入 / 输出坐标约定与数据集一致。
- [x] 几何损失可经 c_k、V 回传笔画模块和 Backbone；新基线不沿用视觉条件 detach，
  否则删除 mask/type 监督后，上游只能从笔画结束任务得到有限监督。
- [x] 保留原实现作为历史对照，采用独立模式 / 模型接口与 checkpoint 版本，避免修改旧运行的解码语义。

## P0：确定训练与推理语义

- [x] 训练时使用标签的有效笔数 K_b 与各笔点数 N_bk 决定展开范围；二级结束预测不执行 break。
- [x] 真实笔数和点数仅用于循环长度、有效位置和监督组织，不嵌入几何头或作为推理条件。
- [x] 每笔从点 BOS 开始，之后始终输入自预测的上一点，不输入真实上一点；
  训练不进行 teacher-forced 坐标反馈，不反馈二值停止事件，连续历史默认完整反传。
- [x] 笔画历史仍为网络生成的 z tokens，当前基线不增加前笔实际轨迹反馈。
  这一限制与“点层能读取本笔历史”区分记录。
- [x] 推理每生成一点先保存几何，再判断本笔结束；本笔结束后检查笔画结束头，
  为最后一笔则结束整字，否则生成下一笔。不能在当前笔尚未画完时因 last 分数直接跳过它。
- [x] 两个结束阈值显式配置并固定初始值0.5；阈值调节只用约定验证集，不使用真实测试长度。
- [x] 推理不读真实笔数、点数、mask、type、起终点或汉字名称，仅以图像为外部条件。
- [x] 明确命名为“自预测几何历史、标签长度展开训练”，不继续称其为完全按预测停止的 free rollout。

## P1：原始点、padding 与长度保护

1915 数据集实测：8990笔，单笔6～338点、均值95.7点、中位数87点；最多13笔/图。
统计依据见本地 [逐笔点数报告](runs/dataset_stats_1915/REPORT.md)。

- [x] 保留原始逐笔采样和书写顺序，首版不做64点或固定点数重采样。
- [ ] 拟合实验前检查原始标签采样密度差异，不将点数误差直接解释为物理路径长度误差。
- [x] 标签坐标采用 x/(W-1)、y/(H-1)、width/S；方形画布 S=H=W，归一化规则写入 checkpoint。
- [x] batch 中按有效笔画、有效点组织长度；已到真实长度的训练样本移出活跃批次或屏蔽，
  padding 不参加几何和结束损失，不将 padding 当作真实 `(0,0,0)` 轨迹。
- [x] 推理达到上限时标记截断，区分正常结束；训练不得静默裁剪标签。
- [x] 新模式保护上限为384点/笔、16笔/图，已用全部1915标签校验可覆盖；它们是保护上限，不是输入给模型的目标数量，也不能推广到其他数据集。
- [x] 记录 batch=24 是图片数量，另报实际活跃笔数、点步数和 microbatch 设置；
  所有降低显存措施保持约定的图片 / 笔画权重，不以梯度累积冒充并行 batch。
  ResNet BatchNorm 的批统计随微批变化，归约一致不代表不同微批策略数值等价。

## P2：仅三个主损失

总目标：

```text
L = lambda_geo * L_geo
  + lambda_point_end * L_point_end
  + lambda_stroke_end * L_stroke_end
```

### 几何损失 L_geo

- [x] 对全部原始有效点的归一化 `[x,y,width]` 使用 L1：

```text
L_geo = mean_over_images(
          mean_over_valid_strokes(
            mean_over_valid_points((abs(dx)+abs(dy)+abs(dwidth))/3)))
```

- [x] 首版不单列 start、delta、length、missing、extra、endpoints、平滑或重绘损失。
  实际轨迹首尾点已包含在几何目标里；几何震荡若仍存在，再作为有证据的后续改进。
- [x] 每图、每笔等权；不因长笔点多、多笔字或尾批而意外改变权重。
  统一画布尺度不等于 xy/width 梯度自然平衡，必须分别记录像素误差。

### 点结束损失 L_point_end

- [x] 一笔真实 N 点：第1～N-1点标签为0，第N点为1。只监督有效位置。
- [x] 使用 BCEWithLogits，首版采用每笔内负样本均值与正样本均值等权：

```text
L_point_end_per_stroke = 0.5 * mean(BCE(logit[t<N],0))
                      + 0.5 * BCE(logit[N],1)
```

- [x] 再按每图有效笔画均值、图片均值归约；若只有1点，缺少负组，仅用正组且重新归一权重。
- [x] 明确这是类别平衡的结束分类，不把输出直接当成未经校准的生存概率。
  推理仍可能过早或过晚结束，训练中忽略 break 不代表该问题已解决。

### 笔画结束损失 L_stroke_end

- [x] 整字真实 K 笔：第1～K-1笔标签为0，第K笔为1；只监督有效笔画。
- [x] 使用与点层相同的正负组平均原则，但归约为每图一次，再对图片平均。
  K=1 时仅计算正组并重新归一；不要将该损失复制到每个点而重复计权。
- [x] 三个 lambda 初始候选均为1；记录原始值、加权值及共享参数上的梯度，
  不把等权或标量 loss 接近当作已平衡的证据。调权重需单独实验。

## P5：基线之后的消融改进

以下不是首版前置条件。每次只加入一个因素，报告质量、停止准确率和成本变化。

- [ ] type 条件：从 z_k 预测类别软嵌入后融合到 c_k，同时恢复 type 主监督。
- [ ] mask 条件：从 z_k 与像素特征生成 mask，再加入视觉 cross-attention 偏置，同时恢复 mask 监督。
  不能只加入未受监督的随机 mask/type 路径；mask 面积不是可靠的笔数预测。
- [ ] type 与 mask 的联合效果；与只有单项时比较，而不是直接启用全部增强。
- [ ] 真实生成首尾点监督、局部位移 / 平滑 / 轨迹mask一致性等几何约束，逐项验证。
- [ ] 前笔实际轨迹反馈到笔画层，检验是否改善全字覆盖与跨笔空间关系。
- [ ] 结束类别平衡、阈值和训练/推理长度差异；数量先作为指标，不默认增设数量头或点数惩罚。
- [ ] 完整按预测停止的 free rollout 微调或其他停止训练策略，明确其额外对齐与监督覆盖要求。
