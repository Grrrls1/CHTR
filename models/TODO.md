# 完全自喂历史的 free rollout 训练 TODO

日期：2026-10-20。本文是改造计划，尚未实现或启动新训练。

## 目标与边界

从 job_237 epoch 100 权重初始化，让点解码器在训练时也只看到自己预测的历史，
逐步 rollout 坐标、宽度和点事件。真实轨迹只用于损失计算，不作为下一步输入。
不使用 scheduled sampling，也不混入 teacher-forced 点历史。

“完全 free”包含两个验收条件：历史点全部来自预测；换笔和整字结束也来自预测。
按真实笔画数、真实点数强制展开可作为诊断对照，但不能作为最终完全 free 训练。
真实 mask、类别和起终点同样不得成为 rollout 条件；图像是推理时唯一外部输入。

## 当前依据

- `networks/model.py` 的 `forward()` 使用真实上一点 embedding，当前是 teacher forcing。
- `networks/autoregressive.py` 已有自喂历史推理，但 `generate()` 使用
  `@torch.inference_mode()`，含离散终止与 CPU/NumPy 导出，不能直接作为训练入口。
- 本次 32 张训练图的 teacher-forced / free IoU 为 0.679 / 0.310；
  teacher-forced 起点误差按图平均约 10.25 px，其他点约 1.07 px。
- 真实 checkpoint 在单样本真实历史下，缓存版与完整前向输出基本一致。
  该检查支持复用缓存计算思路，不能替代训练梯度验证。

## P0：明确 rollout 和监督语义

- [ ] 定义独立训练模式，例如 `training_mode=free_rollout`，保留原模式作对照。
- [ ] 每笔从模型 BOS 开始；之后反馈预测 `[x,y,width,event]`，不得反馈真实上一点。
- [ ] 首版明确采用预测事件 argmax 的 one-hot 历史，与当前 greedy 推理一致。
  argmax/停止分支不可微，事件 logits 仍须接受直接监督；不声称离散决策可直接反传。
- [ ] 连续坐标与宽度默认保留跨步计算图；明确完整 BPTT 的显存成本。
  若实现截断 BPTT，只 detach 预测历史和缓存，不改用真值；记录截断窗口。
- [ ] 换笔后重置点缓存，笔画条件由预测笔画分支生成；整字结束后停止展开。
- [ ] 保留最大 64 笔、每笔 1024 点的保护上限；达到上限标记截断，不伪造结束。
- [ ] 先确定变长预测和真值的监督对应规则，再复用损失。
  预测提前换笔后，不能仍按真实边界直接逐点相减；共同前缀损失也不能成为唯一目标。
- [ ] 为缺失笔画、额外笔画、过早结束和无法结束定义有效惩罚与梯度路径，
  避免“少画少算损失”。评估固定索引、弧长重采样、可微序列对齐或重绘监督的适用范围，
  选定首版方案并写清局限；不把不可微匹配误称为端到端可微。

## P2：损失、日志与训练接入

- [ ] 修复宽度与位置监督的尺度不一致：当前 XY/start/delta 使用像素尺度

  epoch100 平均 width loss 为 0.000308，XY 为 0.0943，start 加权后为 1.9675，
  但宽度 MAE 仍为 4.97 px；不能用小 loss 判断宽度已经拟合。

## P3：验证与实验顺序

- [ ] 防真值泄漏检查：固定图像与模型，改变监督轨迹后，生成历史和终止行为不变，
  只有损失可以改变；预测 mask/类别也不依赖真实值。
- [ ] 梯度检查：未来步损失能通过连续反馈影响更早预测；
  使用截断 BPTT 时仅在声明的边界切断；缓存必须保留相应计算图。
- [ ] 训练和推理在 `eval()`、相同 greedy 策略下输出一致；
  检查缓存、换笔、整字结束、padding 和两个长度上限。
- [ ] 覆盖提前结束、额外笔画与缺失笔画，验证损失不会通过缩短输出逃避监督。
- [ ] 先用“一、抓、映”和复杂字小集做 rollout 前向、反向与短程拟合，

- [ ] 在可用 GPU 上实测 batch=1 的长轨迹反传和显存，再决定 batch、梯度累积、

- [ ] 同配置对比 epoch100 原模型与 free 训练模型：报告 free IoU、teacher IoU、
