CASIA 的“原图参照”指模型本次实际接收的固定 POT 渲染输入，并非独立扫描照片。书法划分不是专门的未见字符类别或未见书家实验。数据与 GT 轨迹未重新制作、未 RDP 简化、未删重复点，也未按预测 cap 截断 GT。

抽样算法：先排序目标域全部 `test_ids`，再用 NumPy `default_rng(seed).choice(..., replace=False)` 抽取。一个 repeat 内无重复，不同 repeat 允许重叠；不声称按 writer 或字符类别分层。全部 10 份清单在首次 test 推理前冻结。每个唯一 ID 对每个模型只推理一次，各 repeat 从同一预测缓存取值。NumPy 版本为 1.23.5。

### 1.5 统计规则

每个 repeat 先按既定指标聚合，再对 5 个 repeat 计算算术均值与样本标准差 `ddof=1`。IoU、DTW/LDTW、笔数误差按字聚合；对齐几何按配对笔画数加权。缺笔、多笔、空输出与截断不剔除；空预测 IoU=0，空序列 DTW/LDTW 标 undefined 并报告数量（本次六组合各 repeat 的 undefined 数均为 0）。

不同 repeat 可能重叠，SD 描述测试抽样波动，不是训练随机种子的稳定性。未做配对 bootstrap 或显著性检验，不将 `SD/√5` 当作独立实验置信区间。配对差值在同域、同 repeat、同 ID 上计算。

## 2. 指标定义与参照

| 指标 | 参照与计算 | 解释 |
| --- | --- | --- |
| AIoU ↑ | 输入图 Otsu 前景，对比预测 XY 中心线在自适应膨胀后的最大 IoU | 忽略预测 W；pen_net_equations_local256_v1；不单独评价笔顺与数量 |
| ImageCharIoU ↑ | 输入图 Otsu 前景，对比预测 XYW 按预测 W 渲染后所有笔画的并集 | 原图参照；不自适应膨胀、不对齐；主表采用该整字指标 |
| OrdIoU ↑ | GT XYW 和预测 XYW 用相同渲染器逐笔重绘；同序 IoU 之和 / max(GT 笔数,预测笔数) | 沿用已测结果；依赖 GT 轨迹；缺/多笔有数量惩罚；不是官方 Order Acc. |
| 旧 CharIoU ↑ | GT XYW 整字并集，对比预测 XYW 整字并集 | 保留作标签参照诊断，不与 ImageCharIoU 混称 |
| DTW / LDTW ↓ | GT 与预测 XY 按笔顺串联，精确欧氏 DTW；LDTW=最优路径累计代价/路径长度 | 256 画布像素单位；依赖 GT 轨迹 |
| XY / W MAE、W bias、终点 L2 | 按同序配对笔画、等归一化序列进度重采样；包含预测首点 | 只覆盖配对笔画，需结合缺/多笔与笔数指标 |
| 笔数 MAE / 正确率 | 预测笔数与 GT 笔数比较 | missing/extra 仅是数量差，不是语义匹配后的漏/多笔 |
| 字符 / 点层截断率 | 分别以整字数 / 预测轨迹数为分母 | 两种率不能混作同一分母 |

**ImageCharIoU 不使用 GT XYW 作为参照；OrdIoU、DTW 和对齐几何仍依赖 GT 轨迹。** `official_implementation_parity=false`。LPIPS、COCO Mask AP、官方 Order Acc. 未实现，均为 N/A；已有 `strict_sequence_mask50` 不冒充这些指标。

### 4.2 可以支持的结论

1. **CASIA 域以 CASIA 原模型最好。** 在主表的 AIoU、ImageCharIoU、OrdIoU、LDTW 与笔数 MAE 上均最佳。迁移模型的三项 IoU 和 LDTW 优于纯书法模型，但笔数 MAE 更高，不能说所有跨域指标均改善。
2. **书法域的迁移模型具有更高的形状重合度。** ImageCharIoU 从纯书法模型的 0.784395 提高到 0.819577（+3.52 个百分点），OrdIoU 从 0.639342 提高到 0.677781（+3.84 个百分点）。这支持整字图像重建与同序笔画轨迹重合度的均值改善；OrdIoU 不等于独立的顺序准确率。
3. **轨迹几何没有同步改善。** 书法域迁移模型的 LDTW 为 5.434910，高于纯书法模型的 4.568692；XY、宽度、终点误差均值也更高。不能概括为迁移模型全面优于纯书法模型。
4. **AIoU 不能单独代表完整轨迹恢复。** CASIA 原模型在书法域 AIoU 最高（0.721171），但 ImageCharIoU 为 0.599277、OrdIoU 为 0.081555，笔数 MAE=9.032，字符截断率=26%。需要联合数量、宽度、几何和有序指标评价。
5. **原域性能保留仍存在差距。** 迁移模型在 CASIA 域的 ImageCharIoU=0.645983、OrdIoU=0.176991，仍低于 CASIA 原模型的 0.694496、0.546137。当前结果显示书法适配与原域性能保留之间存在取舍，但不足以单独认定“灾难性遗忘”。

### 4.3 适合写入论文的表述

> 在固定权重、纯图像输入的双域重复抽样测试中，迁移模型相比纯书法训练模型取得了更高的书法域原图参照整字 IoU 和同序笔画轨迹 IoU，但轨迹几何误差未同步降低，其 CASIA 域性能也仍低于 CASIA 原模型。结果体现出域适配收益、轨迹精度与原域性能保留之间的取舍。由于三组模型的训练数据、预算、历史选优与原生容量不同，这些差值应解释为现有系统比较，不能归因于迁移学习本身的独立因果作用。
