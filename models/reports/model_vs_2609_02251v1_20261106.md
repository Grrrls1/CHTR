# 当前两阶段模型与2609.02251v1的设计对照及研究方向

日期：2026-11-06。对照用户提供的 `/home/lkh/下载/2609.02251v1.pdf`：
En-Guang Wang等，Handwriting Trajectory Recovery via Autoregressive Ordered Stroke Instance Prediction，2026-09-02 v1。
本报告基于实际论文正文及当前主线源码，不使用历史 `networks/model.py` 的旧三任务基线代表当前设计。
仅作阅读与静态分析，没有修改模型、运行测试或提交训练。以下候选创新仅指相对这篇论文的研究假设，不表示已完成全面查新或证明收益。

## 1. 总体结论

当前模型是该论文核心框架的本地复现与书法XYW扩展，而非一套从架构原理上重新提出的方法。
六项关键设计一致：两阶段独立训练、有序笔画自回归、真实历史teacher forcing/预测历史自由推理、首点跨阶段初始化、四尺度串行coarse-to-fine点解码、有效性停止。
最明确的两项结构变动是：删除第一阶段终点辅助头/监督；在两阶段增加宽度W预测并把首点XY扩展为XYW。
其余主要是实现细节、数据渲染、优化预算和评估协议的差异。不能给出有意义的“相同百分比”，因为模块数量和细节重要性不同。

## 2. 按模块对照

| 维度 | 论文 | 当前主线 | 判断 |
| --- | --- | --- | --- |
| 总流程 | 整字图→有序笔画实例→逐笔轨迹→按预测顺序串联；两阶段独立训练（§3.1，pp.6–7） | 同一路线，CASIA两个阶段独立训练，点层冻结参与笔画层串联val | 核心一致 |
| 图像与历史编码 | Swin+Transformer编码整字；共享ResNet提取历史mask的三尺度特征，CLS聚合后融合（§3.2，pp.8–9） | Swin-T、ResNet18、三尺度CLS交叉注意力+FFN；本地FPN与GroupNorm | 结构思路一致，具体型号/归一化等非论文已核实细节 |
| 笔画解码 | 历史+序号+BOS，9层Transformer decoder，预测mask、box、validity、start/end | 历史+序号+BOS，9层；预测mask、box、validity、start XY及首点W | 删除end，增加W |
| 方向监督 | start和end共同作第一阶段辅助监督；只有start传给第二阶段（§3.2，p.9） | 只有start监督，没有end头/损失；start XYW传给点层 | 明确少一项论文组件；终点原本并不作为点层条件 |
| 点层视觉 | ResNet+Transformer+FPN，P5→P4→P3→P2（§3.3，pp.10–11） | 随机初始化ResNet18，C5上2层Transformer，FPN提供四尺度 | 主体一致，型号/C5/层数为本地选择 |
| 点解码 | 因果点历史编码，串行四尺度交叉注意力，块叠4层（§3.3） | 相同主干，每块4次视觉交互，叠4块；pre-norm及每块单FFN | 主体一致，未能确认逐算子等同 |
| 输出与首点 | 每点XY和有效性；首点由第一阶段给定，后续生成及停止 | 每点XYW和有效性；首点XYW直接保留，不能自行修正它 | W扩展；首点初始化机制本身非新增 |
| 层间接口 | 笔画实例及预测起点初始化第二阶段；论文未将预测终点传给点层 | 预测mask覆盖原图、区域外填白，传预测首点XYW；不传隐藏z、end或type | 与论文主要接口一致；灰度提取/阈值细节是本地实现 |
| 第一阶段loss | cls4；mask/dice/box/start/end各5；giou2；中间层辅助监督（§3.4/4.1） | 相同已列系数但无end，增加width Charbonnier×1；辅助层取平均再加最终层 | 删除end、增加W；损失均值/辅助归一化不能假定官方一致 |
| 第二阶段loss | L1(XY)+0.2×BCE(validity) | 同式+1×Charbonnier(W)，按笔等权，几何项只监督第二点起有效点 | 基本loss一致+W扩展 |
| 停止 | 两阶段validity阈值0.5，点尾附invalid | 同样0.5与尾invalid，额外明确区分cap截断 | 一致；截断统计为工程评估完善 |

代码依据：`networks/ordered_stroke.py`、`networks/single_stroke.py`、`networks/two_stage.py`、`losses/ordered_stroke.py`、`losses/single_stroke.py`。
论文没有明确的Swin变体、ResNet型号、隐藏维度、heads、BCE/focal选择、逐算子归一化，不写成已证实的差异或官方设定。

## 3. 训练与数据协议差异

论文§4.1（p.13）明确写出以下设置：

| 项目 | 论文2026-09 v1 | 当前CASIA |
| --- | --- | --- |
| 画布 | 64×64 | 256×256，边距8，4倍超采样 |
| 训练渲染宽度 | 随机1、2、3px | 每字每epoch离散均匀2～12px |
| val/test宽度 | 固定2px | 固定8px |
| 原始轨迹点 | 主实验全部保留；另做RDP消融 | 全部保留，重复点/单点不丢弃 |
| 第一阶段优化 | Adam，lr1e-4，cosine | AdamW，lr1e-4，当前无scheduler |
| 第二阶段优化 | Adam，lr1e-4，cosine | AdamW，lr3e-4恒定 |
| 第一阶段训练 | batch64字，500,000 iterations | 正式CASIA配置batch2字，按epoch训练 |
| 第二阶段训练 | batch512笔，991,000 iterations | job1136实际batch16笔；新配置256笔，val/test128笔，尚未据此宣称已切换运行 |
| 硬件 | 4×RTX A6000 | Slurm单卡5090配置 |
| 内部val划分 | 文中未给出与本地一致的writer24人划分细节 | 官方train240人中seed42取24人val，216人train |

64→256仅作名义4倍尺度换算时，论文训练宽度1/2/3px对应4/8/12px；本地2～12px包含更细笔画和更多中间宽度，并不是完全相同的宽度分布。
论文未明确随机宽度的刷新周期/是否同字统一，本地epoch与sample-id确定宽度属于可复现的实现选择。

重要澄清：这篇论文的第二阶段batch512以“单笔”为单位，当前目标batch256才是相同单位下的一半；2022年PEN-Net的整字batch512属于另一个模型，不能混用。
当前step不能直接与论文iterations比较：4轮本地训练曝光约17,923,524笔；论文991,000×512约507,392,000笔。
所以即使本地累计step已超过991,000，也不意味着达到论文相同训练曝光量。应同时报告训练样本数、优化次数和预算，避免只对比step。

随机笔宽、完整原始点序列、四尺度串行解码、起点初始化都已经出现在这篇论文里，不能作为本地新增创新。

## 4. 评估差异与现在分数的边界

论文主表评价完整纯图片两阶段恢复；论文Table3的GT-stroke诊断也先按真实笔顺重组为整字，再做字符级评价。
当前job1136的AIoU/DTW/LDTW是带真实mask和首点XYW的逐笔等权平均，不能与论文整字分数直接比较。
更高分辨率的DTW/LDTW单位也不同；不能只除4就宣称已实现公平对比，因为归一化、采样、渲染和聚合仍需一致。
论文full-point主表AIoU0.797、LDTW1.74，不能与job1136的逐笔AIoU0.83左右直接排列优劣。

论文报告COCO Mask AP/AP50、严格Order Acc.、AIoU、DTW/LDTW、LPIPS。
本地 `ordered_stroke_evaluation.py` 当前是按序号计算mask IoU及strict_sequence_mask50，并不是COCO AP实现；没有一对一实例匹配式Order Acc.的完整官方等价核验，也未接LPIPS。
本地AIoU遵循PEN-Net公式并穷举至画布饱和，未确认原文实现的候选上限与停止规则一致。

建议比较顺序：固定数据版本/划分→同一输入渲染与采样→整字评价→条件点层诊断→两阶段纯图片结果，分别报告。

## 5. 哪些是补齐基线，哪些可能成为研究贡献

### 5.1 先补齐：恢复终点辅助监督（高优先级，非新创新）

论文第一阶段预测并监督start/end，end仅作辅助，不传给点层；当前删除了它。
论文Table4（p.17）给出了方向相关监督与start初始化的消融，说明此项不是随意附加头。
应在不覆盖现有checkpoint的独立模型版本中恢复end头，先比较有/无end。
这能判断目前偏差是否来自删掉原论文组件，不能把“恢复end辅助监督”包装成创新。
把预测end作为可容错软条件进一步传给点层，则是另一个有别于本文接口的候选实验；仍需核验其他工作，并避免强迫轨迹追逐错误end。

### 5.2 候选A：面向预测mask/首点错误的可靠跨阶段传递（优先）

具体缺口：点层只在真实mask和首点条件下训练，串联时条件来自预测；当前代码将首点直接固定，首点错了点层无法修正第一点。

可实现方案：

- 在训练集内部，用冻结笔画层生成预测条件，或用train/val分析支持的mask形变/首点扰动，混合训练真实与预测条件；不能用test错误分布选扰动。
- 第一阶段输出起点置信度/不确定性；点层用有限幅度残差细化起点，或在少量起点候选间重排，保留整字/历史方向线索。
- 置信度应监督或校准，不能把validity直接当作XY误差置信度。

关键消融：只做噪声训练、只做起点细化、两者结合；对照真实条件和预测条件，画起点误差/遮罩缺损强度与最终轨迹误差的关系。
真实mask/预测mask × 真实首点/预测首点形成2×2诊断；预测笔数不一致时先冻结匹配口径，并把带标签对齐的诊断与完整纯图片分数分开。

创新潜力在“跨阶段误差如何显式建模、如何修正”，不是仅仅添加随机噪声。本文本身已有GT训练/预测推理差异，但没有给出这样的不确定性与可修正首点接口。

### 5.3 候选B：从mask历史升级为方向感知的书写状态（中高潜力）

当前HistoryEncoder只编码历史mask；同一mask不包含写入方向、实际起止和运动趋势。
可将已完成笔画的预测start/end、起始/末端切向及轨迹摘要，与mask表示共同编码，帮助下一笔位置与方向推断。
这比增加通用type分类头更直接地描述“已经怎样写过”。

两种版本应区分：

1. 低成本第一阶段几何历史：用预测start/end等编码，不等待点层完成。
2. 两阶段交替解码：点层生成第k笔后，把轨迹摘要反馈给笔画层再预测第k+1笔；会改变当前先完成所有笔画再批量点解码的推理结构与延迟。

训练时要混合预测历史，不能只用真实方向/轨迹历史而在推理换成错误预测；比较相同计算预算，增加反向/重复笔/交叉字的分析。
相对本文mask历史有明确结构差异；但运动历史、几何token等概念并非天然首创，发表前需专项查新。

### 5.4 候选C：XYW轨迹与笔画轮廓的几何一致性（书法方向优先）

当前宽度只是独立Charbonnier监督。CASIA每字W恒定且首点W已给定，后续复制首点W即可获得很低误差，不能据此证明识别了沿笔变化的真实笔宽。

可实现方案：

- 在CASIA上构造平滑、沿弧长变化的合成W(s)，所有图像/mask/标签同步渲染；首点W只揭示局部宽度，不暴露整条曲线。
- 对XYW渲染的轮廓施加可微覆盖/距离场/边界一致性约束，约束中心线位置与宽度之间的补偿，不直接把非可微AIoU当loss。
- 在书法资产上做独立迁移，检查交叉区域、折钩与收笔的轮廓恢复；评估轮廓误差、中心线误差、宽度沿程误差和停止，不只看面积IoU。

不能声称“首次预测宽度/轮廓”：仓库已有G-HTR参考论文 `references/G_HTR_CVPR2026.pdf`，其任务和方法已经包含笔宽/轮廓建模。
较有价值的定位是“有序两阶段模型中几何与墨迹的一致性及跨域鲁棒性”，须对照XY-only、独立W监督、加入一致性约束三组。
合成W不能解释为真实压力，静态图也不足以唯一识别物理落笔速度和压力。

### 5.5 其他候选（后置）

- 覆盖状态/拓扑约束：将累计覆盖与原图共同作为下一笔条件，减少重复/漏笔；保留交叉处合法重叠，不能强制所有笔画互斥或硬抹掉已覆盖区域。
- 采样密度鲁棒连续曲线：将形状与采样参数化解耦，尝试曲线控制点+可控采样，跨采样密度验证；论文已研究RDP，单独再做RDP消融不是新贡献。
- type软先验：现有TODO已有此路线，但CASIA POT没有逐笔type真值，标签来源/不确定性必须解决；加24类头本身通常不足以构成强创新。
- soft-mask局部证据与联合微调：当前hard threshold和no_grad串联阻断跨阶段梯度。若做端到端一致性，需要明确重写可微训练接口与停止处理，而非把当前独立训练直接叫联合训练。
- KV-cache、减少高分辨率视觉token、共享特征：可改善吞吐，需报告速度/显存/精度Pareto；单纯增大batch不是结构创新。

## 6. 建议的实验顺序

1. 冻结现有XYW基线，完整报告纯图片串联与GT条件诊断；补齐整字聚合及必要的AP/Order Acc.口径。
2. 做“终点辅助监督开/关 × W扩展开/关”的受控消融，先识别与原论文的差异来源；比较时统一渲染、数据、训练预算。
3. 优先选候选A为一条主线，验证从预测条件输入到最终轨迹的收益，而非只提升GT条件点层分数。
4. 若目标是书法/轮廓恢复，再选候选C；候选B适合作为更大架构变化，另计推理代价。
5. 复现实验与方法创新分开表述：端点恢复是补齐；可靠接口/写入状态/几何一致性须由消融和误差分析支撑才形成贡献。

当前不建议同时堆叠end、type、联合训练及多个复杂模块后只报一个总分。先定位预测mask、首点、笔顺、点生成各自的误差上限，再选择针对性机制。
