# CHTR 微创新与服务器实验方案

日期：2026-11-18

## 1. 当前初稿是否包含微创新

当前中英文初稿介绍的是现有分层模型、书法数据准备、变宽轨迹建模和已完成的实验，尚未包含本文提出的新模块或新增损失的实测结果。以下是供服务器实现和验证的候选方案；是否构成最终论文贡献，需要实验结果和后续相关工作核查共同支持。

建议先做两项：**预测条件鲁棒训练（A）＋宽度变化监督（B）**。两者分别针对两阶段误差传递和书法粗细变化，改动相对集中。起点修正（C）与轮廓一致性（D）作为第二轮备选。

## 2. 总览

| 编号 | 候选改进 | 要检验的问题 | 主要改动 | 优先级 |

## 3. 现有实现与统一实验设置

已检查的代码：

- `CHTR/models/networks/single_stroke.py`：点层网络、串行跨尺度注意力和自回归生成。
- `CHTR/models/datasets/single_stroke.py`：真实掩码构造笔画灰度图，历史点预测下一点。
- `CHTR/models/losses/single_stroke.py`：XY 的 L1、宽度 Charbonnier、有效性 BCE。
- `CHTR/models/scripts/train_single_stroke.py`：训练与配置入口。

当前点层损失为：

\[
L_0=L_{xy}+\lambda_w L_w+\lambda_v L_{valid}.
\]

其中 XY 除以 255，宽度除以 256；宽度表示完整笔画直径。每条笔画先按有效点取均值，再在笔画间平均。代码默认权重为 \(\lambda_w=1,\lambda_v=0.2\)，实际实验以服务器保存的配置为准。

统一设置：固定数据划分、256×256 画布、采样方式、解码上限、停止阈值和评估脚本。A～D 第一轮均冻结同一笔画层，仅改变点层。先在书法验证集选择方案，再用书法测试集评估最终配置；CASIA 单独报告，不把两个数据集的指标合并平均。

若采用已有权重微调，所有实验从同一个点层权重出发，训练相同更新步数，并增加“无新模块、相同步数微调”的对照。原始已测模型仅作历史基线，不能用它单独排除额外训练带来的收益。

## 4. A：预测条件鲁棒训练

### 动机与实现

现有点层训练使用真实笔画掩码；实际两阶段推理使用笔画层预测结果。训练条件与使用条件不同，是本项要检验的误差来源。

冻结笔画层，在**训练集**上缓存预测掩码和起点。每个训练样本以概率 \(p\) 使用预测条件，否则使用真实条件：

\[
c=\begin{cases}c_{pred},&u<p,\\c_{GT},&u\ge p,\end{cases}\qquad u\sim U(0,1).
\]

条件 \(c\) 包括掩码和起点。建议先取 \(p=0.5\)，有效后仅在验证集比较 0.25、0.5、0.75。以上是待新增设置，不是现有命令行参数。

实现细节：

1. 优先按现有笔画序号建立配对，记录每个字符的对应关系。缺失笔画回退真实条件；多余预测不强行绑定真实轨迹。报告可配对覆盖率和回退比例。序号错位另作错误分析，不默认为正确配对。
2. 使用现有 `masked_stroke_image`，保持“掩码外为白色、掩码内保留原灰度”的输入方式。
3. 使用预测起点时，更改历史序列的首点；真实的第二点及之后仍作目标，不能把整条真实轨迹跟着平移。
4. 当前生成接口接收首点 XYW。第一轮只替换首点 XY，首点宽度保持基线规则，避免同时引入新的宽度初始化策略。
5. 图像增强时，同步变换预测掩码、预测起点和真实轨迹。缓存仅来自训练集；验证和测试预测不能参与训练。
6. 若训练集预测过于准确，可另外测试训练集误差尺度驱动的起点扰动和掩码边界扰动；单列实验，不混入 A 的主结果。

### 对照与结论判据

| 实验 | 训练掩码 | 训练起点 | 验证内容 |
|---|---|---|---|
| A0 | 真实 | 真实 | 同预算基线 |
| A1 | 真实/预测混合 | 真实 | 对掩码误差的适应 |
| A2 | 真实 | 真实/预测混合 | 对起点误差的适应 |
| A3 | 真实/预测混合 | 真实/预测混合 | 两种条件联合训练 |

主要看真实两阶段自由生成的整字 IoU、有序笔画 IoU、XY 误差和终点误差。若真实条件下提升而预测条件下未提升，不支持“减少两阶段误差传递”的结论。冻结笔画层时，笔画计数准确率应保持不变。

## 5. B：宽度变化监督

### 动机与公式

现有宽度损失约束每个点的宽度，但不显式约束相邻点之间的粗细变化。增加与真实变化一致的差分损失：

\[
L_{\Delta w}=\frac{1}{|\mathcal P|}\sum_{(i-1,i)\in\mathcal P}
\left|(\hat w_i-\hat w_{i-1})-(w_i^*-w_{i-1}^*)\right|,
\qquad L=L_0+\lambda_{\Delta w}L_{\Delta w}.
\]

\(\hat w_i\) 是预测归一化宽度，\(w_i^*\) 是真实宽度；\(\mathcal P\) 只包含同一笔画内连续有效的预测位置。损失拟合真实粗细变化，而不是强迫所有宽度平滑。

当前 `collate_single_strokes` 的输出位置 j 预测真实点 j+1。因此，第一版直接对相邻输出的宽度作差，并用 `valid[:,1:] & valid[:,:-1]` 屏蔽无效配对；不跨笔画、不包含终止点和 padding。有效输出不足两点的笔画不参与该损失均值，避免短笔画稀释监督。该版本不监督固定首点到第二点的宽度变化。

建议起始 \(\lambda_{\Delta w}=0.5\)，验证集候选为 0.1、0.5、1.0。保留原始宽度损失，不用差分项替代绝对宽度项。教师强制训练的收益最终必须通过自由生成验证。

### 数据与判据

返回宽度 MAE、宽度偏差、宽度变化 MAE、整字 IoU和有序笔画 IoU。自由生成长短不同的轨迹先按统一归一化进度重采样到固定数量（建议每笔画 64 点），再计算宽度变化 MAE；所有组使用同一规则，该新增指标单独命名，不混同旧指标。

同时保存真实/预测宽度曲线。若差分误差下降但绝对宽度误差或轮廓 IoU 恶化，说明它只改善了局部变化，不能直接称整体性能提升。

## 6. C：起点残差修正（可选）

当前生成函数直接保留输入首点，点层不能纠正起点本身。新增一个小型 MLP，利用笔画视觉特征 \(f\) 和初始起点 \(s_0\) 输出二维修正：

\[
\Delta s=r\tanh(g([f;s_0])),\qquad
s'=\operatorname{clip}(s_0+\Delta s,0,1),\qquad
L_s=\|s'-s^*\|_1.
\]

\(s_0,s',s^*\) 均为归一化 XY；\(r\) 是最大修正半径，可从 4/255 开始，在验证集比较 2/255、4/255、8/255。损失新增权重先取 1，再由验证集调整。

训练必须提供带误差的起点，否则真实起点对应的零偏移监督无法训练纠错能力。训练和推理都用修正后的首点作为历史输入；输出轨迹的第一点也必须替换为修正点。仅修正 XY，先保留原首点宽度。

与同样使用预测条件训练的 A3 对比：A3 vs A3+C。主要比较起点 L2、终点 L2、XY MAE 和 IoU，并保存修正前后的起点误差。起点改善而整条轨迹未改善时，只能得出局部定位改善的结论。

## 7. D：轨迹轮廓一致性（可选）

用可微渲染器把 XYW 轨迹变为软笔画区域 \(R\)，与真实笔画掩码 \(M\) 比较：

\[
L_{render}=1-\frac{2\sum_u R_uM_u+\epsilon}{\sum_u R_u+\sum_u M_u+\epsilon},
\qquad L=L_0+\lambda_rL_{render}.
\]

\(u\) 是像素，\(\epsilon\) 防止除零。建议以连续线段到像素的距离和插值半宽 \(w/2\) 构造软占据概率，再合并为笔画区域；不要只画离散圆点而忽略点间连接。

第一版可对教师强制输出加固定首点进行渲染，只使用真实有效长度；这仍须用自由生成验证。实现必须保持 XY/W 到损失的梯度；现有硬阈值或 OpenCV 评估渲染不能直接充当训练损失。先在小批量上检查 XY 和宽度梯度，再完整训练。

保留 XY、宽度与有效性损失，以防模型仅靠加粗笔画提高区域覆盖。与同初始化、同预算基线比较，返回 IoU、宽度偏差、XY MAE，以及显存和训练耗时。\(\lambda_r\) 可从 0.01 开始，仅在验证集调节。

## 8. 最小实验矩阵与执行顺序

### 第一阶段：不重新训练的诊断

固定现有模型，分别输入真实/预测掩码与真实/预测起点，组成四组诊断。所有组在同一个固定配对子集上比较并报告覆盖率；另保留完整两阶段测试的缺失/多余笔画统计。真实条件实验是诊断，不是可部署系统性能。

固定预测中心线，比较“训练集确定的全局固定宽度／每笔画首点宽度／现有逐点宽度”三种渲染，检查宽度建模的实际作用。不能用测试集真实宽度给固定宽度方法调参。

### 第二阶段：优先完成四组训练

| ID | A：混合预测条件 | B：宽度差分 | 主要目的 |
|---|---|---|---|
| E0 | 无 | 无 | 相同训练预算对照 |
| E1 | 有，使用 A3 | 无 | 鲁棒训练的独立作用 |
| E2 | 无 | 有 | 宽度变化监督的独立作用 |
| E3 | 有，使用 A3 | 有 | 两项改进是否互补 |

先用同一个随机种子完成四组；选定配置后，对 E0 和候选最佳方案补齐至少三个相同种子，报告均值、标准差与逐字符差值。若要声称两项贡献均稳定，四组均补齐种子。A 有效后再补 A1/A2，预算允许再开展 C、D。

### 第三阶段：现有结构消融（与新模块实验分开）

| 对照 | 验证的设计 |
|---|---|
| 历史输入 XYW vs 历史宽度置零、仍预测 XYW | 宽度历史是否帮助后续轨迹生成；保持输入维度和参数量不变 |
| FPN 融合 vs 去除自顶向下融合、保留四尺度投影 | 多尺度特征融合的作用 |
| P5→P2 vs P2→P5 串行读取 | 由粗到细的读取顺序是否更合适 |
| 串行 vs 并行多尺度读取 | 串行更新查询是否有效；同时报告参数量和计算量 |

这些是待重新训练的消融，不能通过推理时随意删掉训练过的模块替代。原始三组结构消融不是新增微创新。

## 9. 服务器需要返回的数据

每个实验返回一行汇总，以及逐字符结果和固定样例：

| 字段 | 内容 |
|---|---|
| 实验身份 | ID、随机种子、代码版本、配置、初始化与最终权重、训练步数 |
| 数据协议 | 数据集、划分、字符数、画布、采样、停止阈值、解码上限 |
| 主要性能 | 整字轨迹 IoU↑、有序笔画轨迹 IoU↑、XY MAE↓、宽度 MAE↓、终点 L2↓ |
| 专项性能 | 宽度变化 MAE↓、宽度偏差、起点 L2↓（C 必需） |
| 完整性 | 缺失/多余笔画数、笔画计数准确率、截断率、配对覆盖率 |
| 成本 | 参数量、训练耗时、峰值显存、相同硬件与批量下的推理耗时 |
| 可视化 | 同一组字符的输入图、真实/预测轨迹叠图、宽度曲线；包含细笔画、粗细突变、交叠和失败样例 |

书法历史测试可参考 `work/test_job_877/summary.json`；CASIA 历史结果在 `work/eval_epoch_006`。服务器以对应原始汇总为准，不从 PPT 抄数。CASIA 的验证集结果明确标为验证集，另需测试集才能写成测试性能。

建议每组输出 `config.json`、`summary.json`、`per_character.csv` 和 `examples/`，总表保存为 `micro_innovation_results.csv`。未计算的指标写 NA，不写 0。

## 10. 可直接交给服务器执行者的任务

先核对现有基线与评估口径。冻结同一笔画层，基于同一点层初始权重实现 A（训练集真实/预测条件混合）和 B（相邻有效预测点的宽度差分损失），完成 E0～E3 同预算训练。所有模型在相同验证集自由生成并按预先固定的整字轨迹 IoU 选权重，报告辅助指标和逐字符结果。确定配置后补随机种子并进行最终测试，再考虑 C、D。新增训练设置与原有 checkpoint 恢复协议分开处理，不绕过现有配置一致性校验，不覆盖原权重和历史结果。

本文件是实验设计，尚未修改模型代码或运行新增实验。最终初稿只纳入已完成、可核对的结果。
