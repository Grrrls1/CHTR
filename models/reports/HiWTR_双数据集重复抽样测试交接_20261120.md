## 4 抽样与统计默认设置

用户尚未指定抽样量，默认每域每次500个整字样本，重复5次。此处为执行默认，不是已测结果；若预算需要调整，只能在首次test推理前一次性冻结新的数量和次数。

```json
{
  "split": "test",
  "samples_per_repeat_per_dataset": 500,
  "repeats": 5,
  "sampling_seeds": [20261120, 20261121, 20261122, 20261123, 20261124],
  "sampling_unit": "character_image_sample",
  "sampling_method": "uniform_without_replacement_within_repeat",
  "primary_decode_protocol": "native_caps_v1",
  "character_batch_size": 1,
  "point_batch_size": 16,
  "validity_threshold": 0.5,
  "mask_threshold": 0.5
}
```

抽样实现先对该域 `test_ids` 排序，再用 `numpy.random.default_rng(seed).choice(..., replace=False)` 抽取。保存实际ID列表、候选test ID列表哈希、数据指纹、split哈希、NumPy版本、seed和抽样算法，不能只保存seed。

- 同一个域同一次repeat，三组模型必须读取完全相同的manifest，不在各模型内部重新抽样。
- 一个repeat内不重复；不同repeat之间允许重叠，保存重叠/唯一ID数量。这是均匀随机抽样，不冒称按字符类别或writer分层抽样。
- 先冻结全部10份manifest，再开始模型测试，不能看结果后重抽、剔除难例或调整测试集。
- 每个域先取5次子集的并集，对每组固定模型的每个唯一ID只推理一次，缓存完整预测。之后按每次manifest取回预测分别计算指标，避免重叠字重复占用GPU。
- 每个repeat的summary必须写 `full_split=false`、`evaluation_scope=test_subset`，同时保存完整候选test数量和本次实际抽样数量。不能因为覆盖了整个包装后的subset对象就误标为全test完成。
- 逻辑上共有30个“模型×域×repeat”结果，最多15000个模型—字推理案例；并集缓存会减少重复推理，不承诺实际耗时。
- 每次repeat先按既定指标聚合，再对5次结果计算mean和样本SD（ddof=1）。报告每次值、样本量、均值与SD。
- SD描述测试抽样波动，不是训练随机种子的稳定性。重复子集可能重叠，不把5次当独立训练，不直接用SD除以sqrt(5)冒充独立实验的置信区间。
- 三组差值在相同repeat/相同ID上配对计算。若需置信区间，另用预先规定的逐字配对bootstrap，不因显著性结果改变方案。

## 5 推理协议与容量差异

主表使用每组权重的原生上限：M_CASIA为32笔/256点，另外两组64笔/400点，协议ID为 `native_caps_v1`。测量的是已有权重按其原生容量工作的系统性能，必须在总表列明上限、截断数量及比例。

不要在测试时扩展CASIA模型位置嵌入、随机初始化新参数，或默认把另外两组收紧到32/256后仍称为原生性能。GT标签在任何组都不截断，超过预测上限的样本仍保留并正常计入误差、IoU和截断统计。

若后续要分离容量影响，可另开 `shared_caps32_256_v1`，三组统一32笔/256点，不改权重。它是额外的受控推理协议，不能与原生上限结果混在同一汇总中。本轮默认不额外执行，以节省时间。

三组都要执行：整字图像 → 自由生成掩膜/首点/笔数 → 预测掩膜覆盖原图 → 冻结点模型自由生成后续轨迹。`eval()`和`inference_mode()`，不训练、不更新BatchNorm。不输入真实掩膜、首点、笔数、终点或真实序列长度。

## 7 指标和计时

两个测试域都计算同一套定义，按域分表，不把两域分数合并平均：

| 指标 | 口径 |
|---|---|
| AIoU ↑ | 统一 `pen_net_equations_local256_v1`，原图Otsu前景对预测XY中心线自适应膨胀，按整字平均；不使用预测W |
| CharIoU / OrdIoU ↑ | 同一XYW像素渲染；整字并集与同序笔画、数量惩罚，按整字平均 |
| DTW / LDTW ↓ | 256画布XY精确欧氏DTW，按整字轨迹顺序串联；LDTW为最优路径累计代价/路径长度 |
| XY/宽度MAE、宽度bias、终点L2 | 按同序号配对笔画，等归一化序列进度重采样；包含预测首点；带配对笔画总数与未配对数 |
| 笔数MAE / 正确率 | 每字预测笔数与真实笔数比较 |
| 严格序列mask50 | 若实现，复用既有笔数相同且所有同序mask IoU≥0.5定义；不是COCO AP或官方Order Acc. |
| 停止与截断 | 分开报告笔画层字符截断率、点层轨迹截断率，写清分母，不混为一个比率 |
| 漏笔/多笔、空mask、空输出 | 保留所有失败；数量差统计不冒称语义匹配漏笔 |
| 推理时间与显存 | 同硬件、FP32、batch1字、point batch16；报告GPU型号与峰值allocated/reserved |

实现参考：`models/training/casia_benchmark_metrics.py`、`casia_metrics.py`、`two_stage_metrics.py`、`single_stroke_evaluation.py`。保留 `official_implementation_parity=false`，不宣称论文官方等价。CASIA的宽度指标只评价合成标签，不解释为真实书法笔压恢复。

空预测的IoU计0；DTW/LDTW按现有实现标undefined并报告数量，不能用0填充后拉低均值。几何对齐误差不覆盖未配对笔画，因此必须同时报告覆盖与数量指标。

计时从已准备好的256灰度图开始，包含CPU→GPU传输、第一阶段与点层串联，CUDA前后同步；排除模型加载、数据读取/渲染、指标计算、图像和文件写入。先用固定val样本预热，不能通过test调阈值或选权重。缓存预测后的每repeat平均耗时是样本构成下的均值，其SD不解释为重复计时噪声；若需测速重复实验另列。

本任务不额外实现LPIPS、COCO Mask AP或官方Order Acc.；若输出模板包含这些项，未实现写N/A，不冒用现有IoU或strict_sequence_mask50代替。
